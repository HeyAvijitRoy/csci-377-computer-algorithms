## About This Repository

This repository contains programming examples and supplemental materials used throughout the course.

The goal is to help students develop a strong understanding of:

* algorithmic problem solving,
* step-by-step algorithm execution,
* implementation using C++,
* manual tracing,
* algorithm analysis,
* efficiency,
* and comparison of different approaches to solving a problem.

The examples are intentionally designed to remain readable and focused so that the underlying algorithm is easy to study.

---

## Programming Language

Course examples primarily use **C++**.

C++ allows us to study algorithms while working with programming concepts and structures such as:

* variables,
* loops,
* functions,
* arrays,
* vectors,
* recursion,
* searching,
* sorting,
* and other data structures.

The primary focus of this course is **algorithmic thinking and analysis**, not memorizing programming syntax.

## How to Use This Repository

Students should use this repository as a learning and reference resource.

For each module:

1. Open the module folder.
2. Read the module `README.md`.
3. Review the provided code examples.
4. Study the comments included in each source file.
5. Predict how the algorithm behaves before running the code.
6. Compile and test the examples.
7. Modify the inputs and observe how the algorithm behaves.
8. Complete any tracing or practice activities associated with the module.

Do not treat the examples as code that should simply be copied.

The goal is to understand **how and why the algorithm works**.

## Course Approach

Throughout CSCI 377, we will move through several levels of understanding:

**Problem → Algorithm → Trace → Implementation → Analysis → Comparison**

Students should gradually become comfortable answering questions such as:

* What problem does this algorithm solve?
* What are the steps of the algorithm?
* Why does the algorithm work?
* What happens during each iteration?
* How much work does the algorithm perform?
* How does the amount of work change as the input size grows?
* What are the best-case and worst-case behaviors?
* Can another algorithm solve the same problem more efficiently?
